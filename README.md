# TokenWatch · CC Switch 用量 / 余量 / 充值监控台

一个**纯本地的 Windows 桌面小工具**：读取 **CC Switch** 数据库中接入的全部第三方模型
（自动排除 Claude 官方 / Codex），把**各家官网的真实用量**和**本机记录**合成到同一张看板上，
同时实时查询**账户余额**、**资源包余量**、**登录票据有效期**，并提供**一键直达官方充值页**。

- **无第三方依赖**：后端只用 Python 标准库，前端是手写 HTML/CSS/JS，没有任何 npm 包。
- **不出本机**：服务只监听 `127.0.0.1`，凭据只存在你自己的 `%APPDATA%\TokenWatch\`，不上传、不下发前端、不经过任何第三方服务器。
- **数据库只读**：以 `mode=ro` 打开 CC Switch 的 SQLite，绝不写入。

---

## 它解决什么问题

CC Switch 只记录**本地代理看到的那部分**调用。而你在网页控制台里花的钱、跑掉的 Token、
还剩多少额度，它并不知道——尤其走官方直连的模型，本地一条记录都没有。

TokenWatch 的做法是**逐家判定**：

| 该家官网接口状态 | 用量数据取自 |
| --- | --- |
| 拿到真实账单 / 用量（`ok`） | **官网实际扣费口径**，卡片上标注「官网实时」 |
| 未配置凭据 / 票据失效 / 区间内无数据 | **回落该家的 CC Switch 本地记录**，并写明回落原因 |

两套口径在同一个视图里合成展示、逐家标注来源，不给你留一个「这里到底算的谁」的疑问。

## 功能

| 能力 | 说明 |
| --- | --- |
| 用量（官网真实） | DeepSeek / Kimi / 智谱 GLM 直连控制台接口取真实用量；按天、按模型、含输入/输出/缓存 Token 拆分 |
| 用量（本地兜底） | 官网未接通时回落 CC Switch 的 `proxy_request_logs` / `usage_daily_rollups` |
| 趋势图 | 今天 / 3 天 / 本周 / 本月 / 半年 / 全年区间，金额与 Token 两种口径切换，按提供商或按模型两种维度 |
| **分时段定价** | 内置各家官网当前价（DeepSeek 峰谷、智谱 / Kimi 全天同价），算出「综合单价 元/百万 tokens」，直接给出**当前时段性价比最高的模型**与备选 |
| 账户余额 | DeepSeek `/user/balance`、Kimi `/v1/users/me/balance`、智谱账户报表（余额 / 累计充值 / 累计消费） |
| 资源包余量 | 智谱费用账单里的 `deductAfter`，显示通用模型推理资源包剩余 Token |
| Token 折算 | 按近 N 天实际用量混合单价，把剩余金额折算成「≈ 还能调用多少 Token」 |
| 订阅额度 | 智谱 GLM 走 Coding Plan 时显示套餐等级与额度窗口（5 小时 / 本周）剩余百分比 |
| **票据有效期** | 标注网页登录凭据的到期时间（Kimi 读 JWT `exp`；智谱无 `exp` 按经验有效期估算并标「估算」；DeepSeek 视为长期有效）；≤ 7 天给提醒，≤ 2 天转红并推荐优先处理 |
| **余额预警阈值** | 全局一个默认值，**也能按提供商单独设**（留空即回落默认） |
| 充值跳转 | 每张卡片「前往充值 ↗」直达官方充值页，地址可在设置里覆盖 |
| 双主题 | 浅色 / 暗色，跟随本地存储记忆 |

### 关于「官网口径不完整」

有些平台并不把口径开全，界面会**明确标注**而不是把 0 当成真实值：

- **Kimi**：官网只开放消费金额，不提供 Token / 请求数 → 标「金额口径」，Token 列显示 `—`。
- **智谱 GLM**：费用账单有 Token 和金额，但**不提供请求数** → 标「无请求数」，请求列显示 `—`。
  金额统一取账单里的**结算金额（实扣）**，因此与官网费用账单页显示的数值一致；
  若该区间有资源包 / 免费额度抵扣，卡片会补一句「官网计价 ¥X，已抵扣 ¥Y」说明差额来源。

## 快速开始

### 方式一：直接用打包好的桌面版

```bat
dist\TokenWatch\TokenWatch.exe
```

双击即可。运行 `创建桌面快捷方式.bat` 可以在桌面生成图标。

> 窗口用的是系统自带 Edge 的**应用模式**（无地址栏、无标签页），观感与原生应用一致，不需要额外装任何东西。
> 关闭窗口程序即自动退出；若已有一个实例在运行，再次双击只会再开一个窗口。

### 方式二：从源码运行

```bat
启动监控台.bat
```

或手动：

```bash
python server.py            # 默认 http://127.0.0.1:8733
```

**不需要 `pip install` 任何东西** —— 后端是纯标准库。

### 重新打包桌面版

```bat
打包桌面版.bat
```

或手动（需要 PyInstaller，图标相关脚本另需 Pillow）：

```bash
pip install pyinstaller
rm -rf build/TokenWatch dist/TokenWatch   # 必须先删，否则 COLLECT 会去删已存在的输出目录而被拦下
pyinstaller --noconfirm TokenWatch.spec   # 不要加 --clean
```

产物在 `dist\TokenWatch\`。

## 接入官网用量（可选，但强烈建议）

不做这一步也能用，只是数字全部来自本地记录。配置好之后，那家就切到官网真实口径。

打开页面右上角 **「平台凭据」**，按各家提示填：

| 平台 | 需要什么 | 从哪拿 |
| --- | --- | --- |
| DeepSeek | 网页登录 Token（**不是** API Key） | `platform.deepseek.com` 控制台 → F12 Console → `JSON.parse(localStorage.userToken).value` |
| Kimi | `rtoken` + 组织 ID | `platform.kimi.com` 控制台 → F12 Console → `localStorage.rtoken`、`localStorage.currentOrganizationId` |
| 智谱 GLM | 登录票据 JWT | `bigmodel.cn` 控制台 → F12 Console → `localStorage.getItem('bigmodel_token_production')` |

> ⚠️ 这三个都是**网页登录态凭据**，不是 API Key，请只填在本机。
> 它们是纯 HTTP 调用，**不需要常驻浏览器**，关掉浏览器也照样刷新。
> Kimi 的访问令牌会用它自动续期，只有 rtoken 本身失效才需要重取。

凭据保存在 `%APPDATA%\TokenWatch\platform_creds.json`（权限 `600`），
接口**只下发掩码**给前端，页面里看不到原文。

## 目录结构

```
cc-token-monitor/
├─ desktop_app.py          桌面端入口（Edge 应用窗口模式，窗口关闭即退出）
├─ server.py               本地服务 127.0.0.1 · CC Switch 只读 + 各平台官方接口
├─ static/                 前端（index.html / styles.css / app.js，无外部依赖）
├─ 启动监控台.bat           源码模式启动
├─ 创建桌面快捷方式.bat      生成桌面图标
├─ 打包桌面版.bat           重新打包 exe
├─ TokenWatch.spec         PyInstaller 配置
├─ tokenwatch.ico          应用图标
├─ test_real.js            真实数据端到端验收（Playwright，不打桩）
└─ test_unified.js         合成视图一致性回归（打桩版）
```

运行期文件（不进仓库）：

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\TokenWatch\config.json` | 设置（端口、刷新间隔、阈值、充值地址） |
| `%APPDATA%\TokenWatch\platform_creds.json` | 平台登录凭据 |
| `%APPDATA%\TokenWatch\tokenwatch.log` | 运行日志 |
| `%APPDATA%\TokenWatch\edge-profile\` | 应用窗口专用的 Edge 配置目录 |

> 源码模式下这些落在项目目录里，方便调试。

## 设置项

页面右上角「设置」：

- 自动刷新间隔（秒，默认 300）
- 余额预警阈值（¥，默认 30）—— 低于则卡片标黄
- **各提供商单独阈值**（¥，留空即用上面的默认值）
- 默认统计范围（今天 / 3 天 / 本周 / 本月 / 半年 / 全年，默认 本月）
- 每个提供商的**充值页直达地址**

也可以直接编辑 `config.json`。汇率 `usd_cny`（默认 7.10）用于把官网返回的人民币折算成美元口径统一展示，
界面上会同时披露原始人民币金额。

## 支持的平台识别规则

自动识别（可在 `server.py` 的 `detect_kind` 中扩展）：

| 平台 | 识别条件 | 余额来源 | 用量来源 |
| --- | --- | --- | --- |
| DeepSeek | 域名含 `deepseek` | 官方 `/user/balance` | 官方用量接口（按月，含未来日期需裁剪） |
| Kimi / Moonshot | 域名含 `moonshot` 或名称含 `Kimi` | 官方 `/v1/users/me/balance` | 官方 `consumes` 日账单（仅金额） |
| 智谱 GLM | 域名含 `bigmodel` 或名称含 `GLM` | 官方账户报表 | 官方费用账单 `expenseBillList`（无请求数） |

其它中转 / 未内置接口的平台：仍会展示本地用量与官网入口，余额区域提示「未内置接口」，
可在设置里自定义充值直达地址。

## 常见问题

- **余额显示「查询失败」**：多为网络或账号侧问题，卡片上有「前往官网查看余量」兜底链接。
- **用量为零**：本地口径来自 CC Switch 的会话 / 代理记录，只有通过它调用过才会累计；刚接入时为空属正常。
- **某家在这一区间没有用量**：不用当故障看。该家会**从趋势图里去掉**，明细表里仍按其他家的格式显示为 `0`，
  表注补一句「N 家在本区间内没有用量，按 0 计（官网均已接通）」——**不会弹红字警告**。
  想看该家的数据就把区间切到 本月 / 半年 / 全年。
- **卡片上的票据期限显示「估算」**：智谱的网页票据本身**不带过期时间**，是按经验有效期推算的，仅供参考。
- **想要更多平台**：先在 CC Switch 里添加，本工具会自动出现该提供商。
- **改了前端但不想重打包**：直接把 `static/*` 覆盖到 `dist/TokenWatch/_internal/static/` 即可；改了 `server.py` / `desktop_app.py` 才需要重打包。
