# TokenWatch · 多模型用量台

把「你在用哪几家模型、各花了多少钱、余额还够几天」放进一个本地面板里。
不需要 CC Switch，也不需要把 API Key 交给任何第三方 —— 登录一次各家的控制台，
之后自动续期、自动统计。

> 单文件本地服务（Python 标准库）+ 系统 Edge 应用窗口，数据全部留在本机。

---

## 它做什么

四页，对应四个问题：

| 页面 | 回答的问题 |
| --- | --- |
| **总览** | 这个月花了多少？余额还够几天？每天的量长什么样？哪家没接通？ |
| **账户** | 我接了哪些平台？各自余额、票据有效期、用量口径；点卡片可以改凭据或删掉 |
| **模型** | 市面上有哪些模型、各自什么价？勾选我实际会用的，其余不干扰视线 |
| **定价** | 现在这个时段哪家便宜？按我的用量配比折成「元 / 百万 tokens」后谁最划算？ |

金额全站统一人民币（¥）。网页、源码、导出都只有一种币种。

## 快速开始

### 方式一：直接跑源码

```bash
git clone https://github.com/shenghuogaogaoshou-source/TokenWatch.git
cd TokenWatch
python server.py          # 打开 http://127.0.0.1:8733
```

只依赖 Python 3.9+ 标准库，没有 pip 安装步骤。

### 方式二：打包成桌面应用

```bash
pyinstaller --noconfirm TokenWatch.spec          # 目录版 → dist/TokenWatch/
pyinstaller --noconfirm TokenWatchLauncher.spec   # 单文件启动器（放桌面）
```

双击 `TokenWatch.exe` 会起本地服务，并用系统 Edge 的 `--app` 模式开一个无地址栏窗口。
**重新打包前先退出正在运行的实例**，否则输出目录会被占用。

### 第一次使用

1. 打开「账户」页 → 右上角「添加账户」；
2. 选一个平台，填入凭据（登录票据或 API Key），点「测试连接」确认能通，再保存；
3. 回到「总览」——余额、用量、趋势就出来了。

## 支持矩阵

能力分三档，界面会如实标注，不会把「读不到」显示成 0：

| 能力 | 含义 | 平台 |
| --- | --- | --- |
| **可采集明细** | 能拿到逐日、逐模型的用量与金额 | DeepSeek、Kimi、智谱 GLM、中转站（New API / One API，且站点开放日志） |
| **仅余额** | 只有余额与累计消费，没有逐日明细 | OpenRouter、硅基流动 |
| **仅模型比价** | 只能看模型清单与价格，读不到账户数据 | OpenAI、Anthropic、Gemini、xAI、通义千问、豆包、腾讯混元、文心一言、MiniMax |

为什么后一组只能比价：它们的用量接口要组织管理密钥（Admin Key）、云厂商 AK/SK 签名
或 GCP 账单权限，不接受网页登录态。与其造一个假的「0 元」，不如把边界说清楚。

模型清单与价格来自 OpenRouter 的公开目录（约 450 个模型 / 60+ 厂商，四档价格：
输入 / 输出 / 缓存读 / 缓存写），24 小时缓存，可手动点「更新目录」。

## 四页细节

**总览**
- 四个数：可用余额、区间消耗、区间 Token、监控状态
- 每日堆叠柱状图，可切「金额 / Tokens」；横轴始终是区间内的每一天（没量的日子就是 0）
- 明细表一行一家，逐家标注口径：官网实扣 / 官网已接通但区间无用量 / 票据失效 / 未接通

**账户**
- 一个账户一张卡片：余额、票据剩余天数、区间用量、充值入口
- 「账户设置」可以改凭据、换名称、删除账户
- 同一平台可以接多个账号（比如两个中转站），各自独立统计

**模型**
- 按厂商筛选、搜索、只看已选；勾选结果存在本机
- 每行给出输入 / 输出单价（元 / 百万 tokens）与上下文长度

**定价**
- 按当前时段（含 DeepSeek 错峰）算综合单价，给出最便宜的三个
- 综合单价按 `config.json` 的 `price_mix` 配比折算，默认 输入 30% / 缓存 60% / 输出 10%

统计区间六档：今天 / 3 天 / 本周（周一起算）/ 本月 / 半年 / 全年。
**总览带、趋势图、明细表三处永远用同一个区间** —— 这是早期版本踩过的坑。

## 数据口径

- **只用一种币种**：人民币。官网本来返回人民币；少数按美元计价的部分（如 OpenRouter credits、
  New API 的 quota）按 `usd_cny`（默认 7.1）折算，并在界面上写明。
- **区间内没有用量 ≠ 故障**：按 0 计，不弹错误，明细表仍然列出这家。
- **票据失效以实测为准**：智谱网页票据没有 `exp`，按 7 天经验值估算并标「估算」；
  如果本次调用成功，即使估算已过期也标「票据仍有效」。
- **一个数据只查一次**：官网轮询 60 秒，同一次刷新里不会重复请求同一家。

---

## 凭据安全

- 凭据只写本机 `%APPDATA%\TokenWatch\platform_creds.json`，不下发前端、不上传、不进 git。
- 页面上只显示掩码；掩码原样回传时不会覆盖真实值。
- 服务只监听 `127.0.0.1`，不接受外部连接。
- DeepSeek 的控制台接口连续请求会返回 429，已按平台做 90 秒冷却，冷却期内给可读提示。

## 目录结构

```
server.py              本地 HTTP 服务 + 各平台采集 + 定价
desktop_app.py         桌面端入口（起服务 + 开 Edge 应用窗口）
core/
  paths.py             运行期路径（配置 / 凭据 / 本地库 / 目录缓存）
  store.py             本地用量库 usage.db（账户、逐日用量、余额快照）
  catalog.py           模型目录（OpenRouter 公开清单，24h 缓存）
  drivers.py           提供商驱动注册表（15 家 + 中转站）
static/
  index.html           四页骨架
  styles.css           设计系统（浅 / 暗双主题）
  app.js               数据加载、汇总、图表、明细、定价渲染
  accounts.js          添加 / 编辑 / 删除账户
  models.js            模型清单与勾选
  shell.js             页面路由、导轨状态、账户速览
test_unified.js        统一视图回归（打桩平台数据）
test_real.js           实盘回归（真实接口，阈值复位）
```

运行期文件（`%APPDATA%\TokenWatch\`）：

| 文件 | 内容 |
| --- | --- |
| `config.json` | 端口、刷新间隔、余额阈值、汇率、价格配比 |
| `platform_creds.json` | 各平台凭据（明文，仅本机） |
| `usage.db` | 账户表、逐日用量、余额快照 |
| `models_cache.json` | 模型目录缓存 |
| `edge-profile/` | 应用自己的 Edge 配置目录 |

## 设置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `port` | 8733 | 本地端口，被占用时自动往后找 |
| `refresh_seconds` | 300 | 自动刷新间隔（余额轮询固定 60 秒） |
| `low_balance_cny` | 30 | 全局余额预警阈值 |
| `low_balance_by_provider` | — | 按账户名单独设阈值，留空用全局 |
| `days_default` | `month` | 默认统计区间 |
| `usd_cny` | 7.1 | 美元折算汇率 |
| `price_mix` | `{input:.3, cache:.6, output:.1}` | 综合单价配比 |

## 常见问题

**需要装 CC Switch 吗？**
不需要。旧版本从 CC Switch 的本地库读提供商，现在账户由你自己在「账户」页添加。
如果本机还留着 CC Switch，首次启动会把已经填过凭据的三家（DeepSeek / Kimi / 智谱）登记成账户，
不用重新登录。

**为什么某家显示「仅余额」？**
它的官方接口只给余额（OpenRouter 的 credits、硅基流动的 user/info），没有按天明细。
这不是没接通，界面上会写清楚。

**为什么票据会过期？**
网页登录态本来就有有效期：Kimi 的 access token 只有 15 分钟（会自动续期，refresh token 长效），
智谱的 JWT 约 7 天。到期后到「账户 → 账户设置」重新贴一次即可。

**数据会不会传出去？**
不会。所有请求由本机直连各平台官网，没有任何中转服务器。
