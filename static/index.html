数据口径与说明

数据来源：余额与用量尽量取自各平台官方接口（用你的网页登录态直连供应商控制台，即账户实际扣费口径）；官网未接通或该平台不提供明细时，会在同一视图里逐家标注，不混算。平台凭据只保存在本机应用数据目录的 platform_creds.json 中，不会上传、不会被本页面显示原文。

定价：价格取自各家开放平台公开定价页，— 核实；跨模型比价用的是按 输入 30% / 缓存命中 60% / 输出 10% 配比折算出的「综合单价」（元 / 百万 tokens），可在 config.json 的 price_mix 里调整。页面所有金额都是人民币：美元计价的部分已按 ¥7.10/USD 折算（可在 config.json 的 usd_cny 里改汇率）。票据有效期按真实凭据标注（Kimi 读 JWT 的 exp；智谱网页票据没有 exp，按 7 天经验有效期估算并标「估算」），若官网本次查询回报票据失效，则以实测为准。

已接入账户

每张卡片对应一个账户。点「平台凭据」填入该平台的控制台票据或 API Key，之后自动续期、不用重复登录。

账户来自各家官网或中转站，全部在本机完成采集与存储。同一家平台可以接入多个账号（例如两个中转站），分别独立统计余额与用量。
