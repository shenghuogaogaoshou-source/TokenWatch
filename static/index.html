数据来源：余额与用量均尽量取自各平台官方接口（用你的网页登录态直连供应商控制台，即账户实际扣费口径）；官网未接通或该平台不提供明细时，自动回落为该提供商的 CC Switch 本地记录，两者在同一个视图里合成展示、逐家标注来源。只统计已在 CC Switch 中接入的提供商，未接入通道（例如 Codex 直连的 gpt 系列）的用量不会出现在本页。平台凭据只保存在本机应用数据目录的 platform_creds.json 中，不会上传、不会被本页面显示原文。

说明：「当前时段与性价比推荐」里的价格取自各家开放平台公开定价页，— 核实；跨模型比价用的是按 输入 30% / 缓存命中 60% / 输出 10% 配比折算出的「综合单价」（元 / 百万 tokens），该配比可在 config.json 的 price_mix 里调整。Token 折算按近 N 天实际用量混合单价（或模型官方标价）估算。页面所有金额都是人民币：三家官网本来返回人民币；只有 CC Switch 本地记录是美元计价，已按 ¥7.10/USD 折成人民币（可在 config.json 的 usd_cny 里改汇率）。卡片上的「登录票据」是按平台凭据的真实有效期标注的（Kimi 读 JWT 的 exp 声明；智谱网页票据没有 exp，按 7 天经验有效期估算并标「估算」；DeepSeek 为非 JWT 长效凭据），票据将在 7 天内到期时会在明细区顶部给出提醒。在 CC Switch 中新增 / 修改供应商后，本工具会自动同步其平台与模型。
